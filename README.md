## Bird-Strike-Impact-Prediction-for-Aircraft-Using-AI-Models
Machine Learning project for predicting bird strike incidents using aviation and environmental data.

## Dataset
The dataset used in this project is the **Aircraft Wildlife Strikes 1990–2023** dataset from Kaggle.

Source: [Aircraft Wildlife Strikes 1990–2023](https://www.kaggle.com/datasets/dianaddx/aircraft-wildlife-strikes-1990-2023)
